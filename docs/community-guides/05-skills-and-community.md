# 技能藏书与社区：进阶玩法

当你掌握了基础的创作流程后，两个进阶功能能让你的体验更上一层楼：**技能藏书**让 Agent 学会专业写法，**社区**让你与其他创作者交流。这篇介绍这两个功能的用法。

---

## 技能藏书（Skills）

### 什么是技能？

技能（Skill）是一份 Markdown 格式的「方法手稿」，教会 Agent 某种专业创作技巧。比如：

- 「如何写出生动的战斗场面」
- 「如何设计层层递进的悬疑线索」
- 「如何描写修炼突破的仪式感」

安装并启用后，相关 Agent 在创作时会参考这些方法。

### 平台内置技能

灵器 AI 自带 18 个内置技能，覆盖两大类型：

| 题材 | 覆盖环节 |
|------|---------|
| **玄幻/仙侠** | 修炼体系、世界构建、角色设计、情节结构、战斗、修炼场景、日常、润色 |
| **悬疑** | 设定、角色、情节结构、线索、氛围、审讯、推理、润色 |

此外还有知乎盐选风格润色和官方的技能创建器（`skill-creator`）。

### 如何创建自己的技能？

1. 进入**技能管理页**（工作台侧边栏的「技能」模块）
2. 上传或手写一份 `SKILL.md` 文件（最大 64KB）
3. 选择适用的 Agent 角色（总编/世界观设计师/……）
4. **提交审核** — 平台会自动进行安全检查
5. 查看审核结果 — 通过（可入藏）或需修订
6. 确认后安装

> 💡 也可以在总编聊天中输入 `/skill-creator`，总编会引导你逐步创建技能。

### 技能的安全边界

灵器 AI 对技能有严格限制，保证安全：

- 仅允许单个 Markdown 文件（`SKILL.md`）
- 不允许附带脚本、可执行代码、远程下载
- 不允许定义新工具或安装依赖
- 技能**不会扩展** Agent 的工具权限，只提供写作方法指导

### 按项目启用

安装后的技能可以在每个项目里单独开关：

- 进入项目的技能管理页
- 在「PROJECT LOADOUT」列表中切换开关
- 只有开启的技能才会被该项目的 Agent 读取

## 社区

### 社区是什么？

灵器社区（`/community`）是创作者交流的地方，**无需登录即可浏览**，登录后可以发帖、点赞、评论。

### 四个内容标签

| 标签 | 用途 | 特点 |
|------|------|------|
| 📄 **文章** | 创作经验、使用教程、设定分享 | 支持点赞、收藏、评论，可设为精华 |
| 🐛 **Bug 提交** | 反馈平台问题 | 点赞即「我也遇到」，状态：open/fixed/closed |
| 💡 **功能请求** | 建议新功能 | 点赞即「投票」，状态：open/planned/shipped/declined |
| 📢 **官方公告** | 平台动态 | 仅管理员发布，默认关闭评论 |

### 社交功能

- **点赞 / 投票** — 对文章点赞，对 Bug 表示「我也遇到」，对功能请求投票
- **收藏** — 收藏有用的文章
- **评论** — 支持楼中楼回复
- **关注作者** — 关注喜欢的创作者
- **作者主页** — 查看作者的资料、文章数、粉丝数
- **我的反馈** — 在 `/community/my-feedback` 查看你提交的 Bug 和功能请求状态

### 发帖前准备

发布社区内容前需要：
1. 已登录
2. 已设置昵称（在 `/profile` 页设置）

> 💡 如果发布时提示「请先设置昵称」，点击提示中的链接前往个人资料页设置即可。
