# 文档系统全解：十一种类型、编辑与导出

灵器 AI 的所有创作内容都以 Markdown 文档的形式存储和管理。这篇详解文档系统的方方面面——从十一种文档类型到编辑器、保存机制和导出功能。

---

## 十一种文档类型

每个项目的内容按模块组织，对应十一种文档类型：

| 文档类型 | 所在模块 | 内容 | 关键字段 |
|---------|---------|------|---------|
| `worldview` | 世界设定 | 世界观条目 | 类别、名称、重要度（1–10）、关联角色/章节 |
| `character` | 角色档案 | 人物档案 | 名字、角色定位（主角/反派/配角）、能力、成长阶段 |
| `relationships` | 角色档案 | 人物关系 | 双方关系、紧张度 |
| `volume` | 故事大纲 | 卷概要 | 卷号、标题、章节列表、字数目标 |
| `chapter-card` | 故事大纲 | 章节卡 | 章节、视角、出场角色、世界元素、伏笔、情绪曲线 |
| `foreshadow` | 故事大纲 | 伏笔记录 | 编号（fs-001）、重要度、埋设章节、计划回收、实际回收、状态 |
| `director-script` | 导演剧本 | 章节导演剧本 | 章节、依据、角色引用、世界引用、前章 |
| `chapter-text` | 章节正文 | 最终正文 | 章节、卷、视角、字数、出场角色、风格标签 |
| `chapter-skeleton` | 故事大纲 | 章节骨架 | 章节目标、冲突、场景和关键节点 |
| `story-summary` | 连续性档案 | 故事至今 | 最新章节、已发生事件、当前主线和未解决问题 |
| `character-state` | 连续性档案 | 角色状态 | 角色、最新章节、位置、目标、关系和状态变化 |

其中，`foreshadow` 同时可以在故事大纲和连续性档案中访问：大纲负责规划伏笔，连续性档案负责查看场记在章节确认后推进的生命周期。

### 交叉引用

文档之间通过字段互相引用，这是 Agent 上下文检索的基础：

- `worldview.related` → 关联的角色、章节、其他世界元素
- `character.appears_in` → 该角色出场的章节
- `chapter-card.foreshadow_plant/resolve` → 本章埋设/回收的伏笔
- `story-summary.latest_chapter`、`character-state.latest_chapter` → 连续性档案跟踪到的最新章节

> 💡 这些关联让导演和作家在写每一章时，能自动拉取到相关的世界设定、角色档案和前文内容。

### 连续性档案

章节正文从草稿确认后，场记会自动收束连续性信息。你可以在「连续性档案」工作区查看滚动摘要、角色状态和伏笔文件；工作区顶部还会显示摘要或角色状态是否落后于最新已确认章节，以及伏笔是否逾期。

## 文档状态

每份文档有三种状态：

```
草稿 (draft) → 已确认 (confirmed) → 已锁定 (locked)
```

只有你确认后，总编才会推进状态。锁定后的文档不再变动，保证已确认的内容不被意外修改。

## 编辑器功能

点击中栏任意文档即可打开编辑器：

- **编辑 / 预览切换** — 左侧 Markdown 编辑，右侧实时预览
- **快捷键保存** — `Ctrl/Cmd + S`
- **保存状态** — 右上角实时显示「已保存 / 未保存 / 保存中 / 保存失败」
- **冲突检测** — 如果你和 AI 同时编辑了同一文档，系统会提示冲突，你可以选择保留自己的版本或加载 AI 的版本

### 冲突处理

当 AI 和你同时修改同一文档时：

1. 保存时检测到版本哈希不一致（409 冲突）
2. 弹出冲突对话框，显示本地版本和远程版本
3. 你可以选择**保留本地**或**重新加载远程版本**

> 💡 建议：和 AI 协作时，避免在同一文档上同时编辑。先等 AI 完成修改，再做你的调整。

## 会话（Session）与记忆

左侧栏可以管理多个聊天会话：

- **创建会话** — 不同创作方向用不同会话（如一个聊世界观，一个聊大纲）
- **归档会话** — 不再需要的会话可以归档
- **会话记忆** — 系统会自动提取对话中的关键信息形成记忆，帮 AI 记住你的偏好和设定

> 💡 会话记忆是异步后台运行的。如果记忆状态显示「degraded」，可以稍后再试或在新会话中重新说明关键设定。

---

## 导出功能

月卡会员可以导出文档：

- **Markdown (.md)** — 带 frontmatter 的原始文件
- **纯文本 (.txt)** — 仅正文内容
- **Word (.docx)** — 排版后的 Word 文档

在章节正文页面，点击导出按钮选择格式即可。

> ⚠️ 导出功能需要**月卡会员**。非会员可以在编辑器中查看全文，但无法下载文件。
