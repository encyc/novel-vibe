# 认识你的七位创作搭档：Agent 系统详解

灵器 AI 不是单一的 AI 写作工具，而是一个由**总编 + 六位专业 Agent 协作**的创作团队。你只需要和总编聊天，总编会自动调度六位专家完成从世界观到正文，再到连续性维护的全流程。

这篇帮你理解每位 Agent 的角色，以及它们如何协作。

---

## 七位 Agent 各司其职

| Agent | 角色 | 负责什么 |
|-------|------|---------|
| 🎩 **总编** (Chief Editor) | 你的唯一对话入口 | 理解创作意图，分解任务，调度其他 Agent，审阅产出一致性，控制文档状态 |
| 🌍 **世界观设计师** (Worldbuilder) | 构建虚构世界 | 地理、力量/修炼体系、势力阵营、历史、世界规则 |
| 👤 **角色设计师** (Character Designer) | 塑造人物 | 人物档案、性格弧线、关系网络、行为特征 |
| 📋 **大纲师** (Outliner) | 设计故事结构 | 三幕/多线结构、卷章划分、节奏、伏笔埋设与回收 |
| 🎬 **章节导演** (Chapter Director) | 统筹单章 | 收集上下文，拆分场景，情绪曲线，对话提示，章节钩子 |
| ✍️ **章节作家** (Chapter Writer) | 撰写正文 | 将导演剧本转化为小说文字——描写、对话、节奏 |
| 🗂️ **场记** (Script Supervisor) | 维护连续性 | 在章节正文确认后，更新故事至今、角色状态和伏笔生命周期，帮助后续章节保持前后一致 |

> 💡 你**只和总编对话**。其他六位 Agent 由总编在幕后调度；场记通常在章节正文确认后自动运行，它的产出会写入连续性档案。

---

## 委托机制：总编如何调度

当你提出一个创作需求时，总编会：

1. **分析需求** — 判断需要哪些 Agent 参与
2. **委托任务** — 通过 `delegate_to_agent` 工具把具体任务分发给对应 Agent
3. **收集产出** — Agent 完成后将结果返回给总编
4. **审核一致性** — 总编检查各 Agent 产出之间是否有矛盾
5. **汇报给你** — 总编汇总结果，在聊天中展示给你审阅

章节正文确认后，系统还会自动创建一个连续性维护任务交给场记。场记会维护以下档案：

- `summary/story-so-far.md`：滚动记录故事进展
- `characters/{slug}-state.md`：记录角色在最新章节后的状态
- `foreshadowing/fs-{NNN}.md`：逐条推进伏笔的埋设、回收或废弃状态

你可以在工作台的「连续性档案」模块查看这些文件，以及摘要、角色状态或伏笔是否落后于最新已确认章节的提示。

例如你说「帮我设计主角的角色」，流程是：

```
你 → 总编：「帮我设计主角」
     总编 → 角色设计师：设计主角档案
     角色设计师 → 总编：返回角色设定
     总编 → 你：展示角色设定，等待确认
```

## 文档状态流转

每份创作文档都有三个状态阶段：

```
草稿 (draft) → 已确认 (confirmed) → 已锁定 (locked)
```

| 状态 | 含义 | 谁能改 |
|------|------|--------|
| `draft` | 刚生成，待审阅 | 总编可修改 |
| `confirmed` | 你已认可 | 总编可修改 |
| `locked` | 已锁定，不再变动 | 任何人不可改 |

> ⚠️ **重要**：只有你（作者）确认后，总编才会把文档状态推进到 `confirmed` 或 `locked`。你始终拥有最终决定权。

---

## 删除保护协议

AI 可能会建议删除旧文档来替换为新版本。为防止误删：

- **六位专业 Agent 无法直接删除文档**——即使它们「看到」了删除工具，执行时会被自动拦截
- 它们只能**提出删除请求**（附上理由），由总编转达给你
- **总编只有在确认后**才会真正执行删除

这意味着你的创作数据不会因为 AI 的自主决策而丢失。

---

## Web 搜索能力

当 Agent 需要现实世界的事实（如某个历史事件、地理知识），它们不能自己上网搜索：

1. 专业 Agent 发出 `[WEB_SEARCH_REQUEST]` 请求
2. 总编执行网络搜索
3. 总编将搜索结果反馈给对应 Agent

> 💡 这保证了 Agent 专注于创作，同时需要时可以获取准确的外部知识。

---

## 小结

- 你只和**总编**对话，不用管幕后调度
- 七位 Agent 分工明确：总编、世界、角色、大纲、导演、作家、场记
- 场记在章节确认后维护连续性档案，帮助后续章节继承最新状态
- 文档状态 `draft → confirmed → locked`，你掌握确认权
- 删除需审批，AI 不会擅自删你的东西
