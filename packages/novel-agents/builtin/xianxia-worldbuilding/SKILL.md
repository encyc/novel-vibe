# 仙侠世界观构建

修炼体系定义了"人可以有多强"，世界观定义了"这个世界值得探索"。一个出彩的仙侠世界让读者愿意在其中流连——每个宗门背后有千年恩怨，每处秘境都藏着失落文明，每个坊市传言都可能指向惊天机缘。本技能覆盖二十余年网文经典中的世界构建范式，帮助你打造一个让读者相信"真实存在"的修真界。

## 设计原则

1. **世界是主角的阶梯**。世界的广度和层次决定了主角能走多远。如果人界的地图只有三个宗门，主角成长到金丹期就没有舞台了。从《凡人》的人界→灵界→仙界，到《完美世界》的八域→九天十地→异域，经典作品通过"换地图"不断刷新读者的探索欲。

2. **每一处设定都要有叙事回声**。不要为了设定而设定。"北冥冰原"不只是地图上的一个地名——它应该曾经发生过改变世界格局的大战，埋藏了某件至宝，影响了某个宗门的兴衰。读者下一次听到"北冥冰原"时会自然地紧张——这就是世界设定的叙事回声。

3. **冲突源于资源分布不均**。灵脉在哪里，宗门就在哪里；宗门在哪里，冲突就在哪里。仙侠世界的核心矛盾（宗门战争、秘境争夺、正魔对立）都可以追溯到资源的地理分布。让读者理解"为什么打"比"打得怎么样"更重要。

## 一、世界的层次结构

仙侠世界通常不是单一平面，而是垂直分层的立体结构。

### 1.1 经典三层结构

《凡人修仙传》定义了最经典的"下界→灵界→仙界"三层模型：

```
仙界（真仙界）
  ↑ 大乘渡劫后飞升
灵界（上界）
  人族三皇境 + 妖族七王 + 无数大陆与海域
  ↑ 化神后飞升
人界（下界）
  天南 / 乱星海 / 大晋 / 极西之地 / 五龙海
```

三层结构的核心优势：
- **每一层有明确的力量上限**。人界元婴是巅峰，灵界大乘是巅峰，仙界道祖是至尊。避免了"第一章就告诉你世界最强者是谁"的尴尬。
- **飞升 = 故事重启 + 张力的延续**。主角在人界已是至尊，飞升灵界后重回底层——这种"从王者到蝼蚁"的切换是仙侠最经典的张力引擎。
- **每层有独立的文化生态**。人界宗门林立、资源稀缺；灵界万族争霸、法则初现；仙界势力固化、道统之争。

### 1.2 其他层次模型

| 作品 | 空间结构 | 特色 |
|------|---------|------|
| 《遮天》 | 北斗星域→紫微星域→永恒星域→飞仙星，各星域由星门/五色祭坛连通 | 横向扩展而非垂直飞升，每个星域有独立文明 |
| 《完美世界》 | 八域（下界）→ 九天十地 → 异域 → 界海 → 上苍之上 | 从碎片化下界到完整上界再到域外威胁，层层展开 |
| 《莽荒纪》 | 三界（盘古/无间/三千大世界）→ 混沌世界 → 终极之道 | 从神话出发的宏大尺度 |
| 《仙逆》 | 朱雀星（洞府界）→ 联盟星域 → 封界 → 仙罡大陆 | 连环套娃式展开，每层都是更大世界的"牢笼" |
| 《剑来》 | 浩然天下 → 青冥天下 → 莲花天下 → 五彩天下（飞升城）→ 蛮荒天下 | 多个"天下"平级存在，以文运/武运/剑气区分 |

### 1.3 选择你的世界层次模型

回答三个问题：
- **你的故事需要几次"从零开始"？** 每次飞升都是一次重置——三次飞升意味着主角需要经历三次"从蝼蚁到王者"的旅程。大多数作品用 1-2 次飞升就够了。
- **每层世界的核心魅力是什么？** 人界的魅力在"宗门争霸"和"秘境冒险"；灵界的魅力在"万族博弈"和"法则感悟"；仙界的魅力在"道统之争"和"超脱之路"。
- **层次之间如何连通？** 飞升通道（天劫飞升/跨界传送阵/空间裂缝）、飞升条件（境界+渡劫/特殊机缘）、飞升后的信息隔离（上下界通讯是否可能？）。

## 二、宗门与势力格局

宗门是仙侠世界的权力单元、社交网络和冲突引擎。一个好的势力格局让读者一眼看清"谁打谁、为什么"。

### 2.1 势力分类体系

```
正道势力：
  正道魁首（太上门/天道宗/浩然宗）—— 一宗压天下，通常执掌修仙界的秩序
  顶级宗门（万剑宗/太虚门/玉清宫）—— 有化神/大乘坐镇的巨擘
  一流宗门 —— 有元婴坐镇的地方霸主
  二三流宗门 —— 金丹/筑基为主的区域性势力
  散修联盟 —— 无宗门的散修组成的松散组织（情报/交易互助）

魔道/邪道势力：
  魔道巨擘（万魔殿/血神教/鬼灵门）—— 与正道魁首对标的终极反派
  魔道分支 —— 血道/鬼道/尸道/魂道/毒道 各有势力
  邪修散人 —— 独行魔头，战力常高于同阶正派修士

中立/特殊势力：
  炼丹师公会 —— 掌握丹药供给，跨宗门的影响力
  炼器师公会 —— 掌握法宝供给
  阵法师联盟 —— 掌握护山大阵和传送阵技术
  商盟/拍卖行 —— 跨越正魔的中立交易网络
  杀手组织/暗阁 —— 接受灵石雇用的暗杀势力
  情报组织（天机阁/万象楼）—— 贩卖情报，通常是最大的信息不对称者

上古/隐世势力：
  上古世家 —— 传承数十万年，血统至上
  隐世宗门 —— 关闭山门万年，每逢大劫出世
  古族/遗族 —— 非人族的古老种族（龙族/凤族/鲲鹏遗族）
```

### 2.2 势力设计方法论

**势力三角**（确保格局有张力）：
```
         正道魁首
          /    \
         /      \
    互相制衡   共同敌人
       /          \
  顶级宗门A ──── 顶级宗门B
       \          /
        \        /
         魔道巨擘
```
在这个三角内：正道之间貌合神离（资源竞争/道统之争）、正魔之间势不两立（但交易从未停止）、魔道内部也互相吞噬。每一对关系都可以产生剧情。

**势力设计的四个变量**：
1. **体量** —— 有多少修士？控制多少灵脉？占多少地盘？
2. **传承** —— 有多少年历史？祖上出过什么大人物？有什么镇派功法或法宝？
3. **立场** —— 对散修的态度？对魔道的态度？对外来飞升者的态度？
4. **内部矛盾** —— 任何大势力内部都不可能铁板一块。掌门vs太上长老/激进派vs保守派/主家vs旁系。

### 2.3 经典作品中的势力格局

| 作品 | 势力格局 | 可借鉴点 |
|------|---------|---------|
| 《凡人修仙传》 | 天南七宗+乱星海星宫/逆星盟+大晋三大宗门+灵界万族 | 同一世界不同区域的势力完全不同，文化差异极大 |
| 《遮天》 | 北斗星域六大圣地（荒古世家/圣地/皇朝）+ 生命禁区 | "禁区"概念——上古至尊自斩修为后蛰伏之地，是悬在所有势力头上的达摩克利斯之剑 |
| 《斗破苍穹》 | 中州"一殿一塔二宗三谷四方阁" | 以数字口诀概括势力格局，极其利于读者记忆和传播 |
| 《完美世界》 | 八域各自独立→九天十地→异域入侵 | 势力格局随世界展开而重构——前期的顶级势力到后期只是炮灰 |
| 《仙逆》 | 朱雀星→天运星→联盟星域→封界 | 每一层的势力都是上一层的"棋子"，营造"山外有山"的惊悚感 |
| 《剑来》 | 浩然天下（儒教+剑修）→ 青冥天下（道教）→ 莲花天下（佛教） | 以宗教/道统划分天下，每个天下有不同的修炼哲学 |

## 三、地理与灵脉

地理决定资源分布，资源分布决定势力格局。仙侠世界的地图不是画着好看的——每一座山的位置都应该可以用"灵脉走向"来解释。

### 3.1 灵脉体系

```
灵脉等级与产出：
  微型灵脉 —— 仅供 1-2 人修炼，产出下品灵石
  小型灵脉 —— 小型家族/筑基散修的安身立命之本
  中型灵脉 —— 普通宗门根基，产出中品灵石，面积覆盖数十里
  大型灵脉 —— 一流宗门根基，产出上品灵石，伴生灵石矿
  巨型灵脉 —— 顶级宗门/皇朝根基，覆盖千里
  祖脉/龙脉 —— 贯穿整片大陆的灵脉主轴，决定一界的灵气浓度

灵脉的关键特性：
  - 不可再生（开采过度会导致灵脉枯竭，宗门迁址是常态）
  - 可争夺（灵脉是战争的终极原因）
  - 可培养（高级修士坐化后灵力归还天地，可提升灵脉品质——《凡人》中元婴修士坐化可维持中型灵脉数百年）
```

### 3.2 标志性地貌设计

仙侠世界需要几个让读者记住的"地标"。不同地貌天然适配不同的势力、剧情和氛围：

```
标志性地貌类型：
  灵山（仙家洞府/宗门驻地）
    例：《遮天》的不死山（生命禁区）、紫山（无始大帝道场）
  禁地/绝地（生灵勿入的危险区域）
    例：《凡人》的坠魔谷（上古战场遗迹，空间裂缝密布）
    例：《遮天》的七大生命禁区（荒古禁地、太初古矿等）
  海域（资源丰富但危机四伏的自由区）
    例：《凡人》的乱星海（散修和海盗的天堂，兽潮是最大威胁）
  沙漠/荒原（上古战场遗迹，通常藏有大机缘）
    例：《完美世界》的石村外的无尽大山
  秘境/洞天（独立空间，内含上古传承）
    见第四节
  域外战场（跨界连接处，万族混战前线）
    例：《凡人》灵界篇的天渊战场
```

### 3.3 地理构建方法论

**三步法**：
1. **先定灵脉走向** → 沿灵脉分布宗门/城池/坊市
2. **再设交通网络** → 传送阵/灵舟航线/凡人道路 → 连通各节点
3. **最后填空白区域** → 妖兽森林/散修密地/未探索禁区 → 留给主角"探险"

**距离与时间**：网文读者需要直观理解空间尺度。
- 筑基修士飞行速度 ≈ 日行千里
- 元婴修士御剑 ≈ 日行万里
- 跨大陆传送阵 ≈ 即时（但极昂贵，且通常有使用限制）
- 建立统一的速度-距离体系，避免"第一天飞了三天路，第二天御剑半天到"

## 四、秘境与洞天

秘境是仙侠世界最核心的"探险-收获"机制。如果说宗门战争是横向的权力冲突，秘境探险就是纵向的机缘获取。两者交替，构成仙侠最经典的叙事节奏——"打了宗门战，进秘境升级，出来再用新能力打宗门战"。

### 4.1 秘境分类

```
按来源分类：
  上古大能洞府 —— 某位飞升/陨落的大修士遗留的小世界
    └─ 通常有禁制/考验/传承碑
  天然洞天福地 —— 天地孕育的灵力集中区域
    └─ 内含天材地宝/先天灵物，但可能有原生守护兽
  古战场遗迹 —— 上古大战的废墟
    └─ 残留的法则碎片/功法残卷/未散的神念（对悟道有奇效）
  试炼之地 —— 先贤为后辈专门设计的"考场"
    └─ 分级挑战/奖励机制/排名体系（天然的竞争舞台）
  跨界裂缝 —— 两个世界之间的非稳定通道
    └─ 可能有异界来客/稀有异界材料

按开放机制分类：
  定时开放（每百年/千年自动开启一次）—— 制造"集结等待"的期待感
  定点开放（需要特定条件：钥匙/阵法/血脉/修为境界）—— 推动特定剧情
  永久开放（但越深入越危险）—— 持续性的探索驱动力
```

### 4.2 秘境设计的叙事功能

好秘境不只是打怪爆装备的地方——它应该是：

| 叙事功能 | 经典案例 |
|---------|---------|
| **揭示历史的窗口** | 《凡人》坠魔谷中发现的古修士遗骸和玉简，揭示了上古大战的真相 |
| **角色关系的催化剂** | 秘境中被迫合作/互相背叛，比日常社交更能暴露角色本质 |
| **成长加速器** | 外界需要百年修炼的东西，在秘境中获得（但有代价或限制） |
| **势力洗牌的导火索** | 《遮天》中荒古禁地每次异动，各大圣地都倾巢出动 |
| **伏笔的埋设点** | 秘境中发现的神秘石板/古文字/残缺地图，指向更大的秘密 |

### 4.3 秘境设计模板

设计一个秘境时，回答以下问题：

```
名称：_________
来源/创建者：_________（上古大能？天然？）
开放条件：_________（定时？条件触发？永久？）
准入限制：_________（境界上限？人数限制？）
核心吸引力：_________（传承？灵药？功法？悟道机会？）
主要危险：_________（禁制？守护兽？空间裂缝？人心险恶？）
层级结构：_________（一层？多层？每层的难度和奖励梯度？）
历史悬念：_________（这里曾经发生过什么？有什么未解之谜？）
```

## 五、修真社会结构

修真界不是一群修士在打架——它是一个有经济、法律、文化、阶层流动的"社会"。构建合理的修真社会，让读者感受到"这个世界在主角不在场的时候也在运转"。

### 5.1 修真界的阶层分化

```
顶层：大乘/渡劫期 —— 极少露面，已是"传说"般的存在
  │  数量：一界可能只有个位数
  │  关注：飞升/道统传承/种族存亡
  ▼
高层：化神/炼虚期 —— 顶级宗门的话事人
  │  数量：数十至上百
  │  关注：宗门兴衰/灵脉争夺/法则感悟
  ▼
中层：元婴期 —— 地方霸主、宗门长老
  │  数量：数百至上千
  │  关注：冲击化神/争夺稀有资源/培养弟子
  ▼
基层：金丹/筑基期 —— 宗门中坚、散修主体
  │  数量：数以万计
  │  关注：获取筑基丹结丹丸/加入好宗门/在坊市混出样子
  ▼
底层：炼气期 —— 凡人入道的起点
  │  数量：不计其数
  │  关注：生存/入门功法/不被妖兽吃掉
  ▼
根基：凡人世界 —— 宗门的新血来源
     数量：以亿计
     与修真界的互动：宗门定期"收徒"/灵根检测
```

### 5.2 坊市与交易体系

```
坊市等级：
  草市（炼气/筑基级）—— 散修自发聚集，以物易物为主
  坊市（筑基/金丹级）—— 宗门驻地/交通要道，有固定店铺
  大型坊市（金丹/元婴级）—— 具备拍卖行、炼丹阁、炼器坊的完整商业区
  超级坊市/商会总部 —— 跨大陆交易网络、天材地宝集散地
                          例：《凡人》中的"天渊坊市"

关键商业节点：
  拍卖行 —— 高端物品交易、竞价场景、信息交换中心
            一年一度/十年一度的大拍卖会是天然的剧情高潮节点
  丹药阁 —— 修炼加速器和突破辅助的供给站
  炼器坊 —— 法宝定制/修复/升级
  符箓店 —— 一次性战斗消耗品
  灵兽行 —— 战斗伙伴/坐骑交易
  情报贩子 —— 地图/秘境线索/仇人行踪
```

### 5.3 散修生态

散修是仙侠世界最庞大的修士群体——不隶属任何宗门，自力更生。

```
散修的典型生存策略：
  - 加入坊市做护卫/炼丹助手/炼器学徒
  - 组团猎杀妖兽获取材料贩卖
  - 接受宗门发布的悬赏任务
  - 在秘境开放时冒死进入（死亡率最高、收益也最高）
  - 依附大型势力做外围成员

散修的叙事价值：
  - 主角通常是散修（或小宗门出身），散修视角天然具有"底层逆袭"的代入感
  - 散修群体是信息的"毛细血管"——坊市传言/秘境消息通过散修网络传播
  - 海量散修被动员起来时，会形成改变势力格局的力量
    （《凡人》乱星海的散修联盟就是范例）
```

### 5.4 修真界的文化与习俗

让世界"活"起来的细节：
- **收徒大典**：宗门定期检测凡人和低阶修士的灵根，是底层向上流动的主要通道
- **宗门大比**：定期举办的比武大会，决定资源分配和弟子地位。天然的"竞技场"剧情段落
- **论道大会**：高阶修士的学术交流会，交换修炼心得和道法见解。通常是情报交换的隐蔽场合
- **炼丹/炼器/阵法大赛**：专业能力比试，冠军可获得稀有材料或功法
- **秘境潮**：知名秘境即将开启时的"淘金热"，天南海北的修士朝一个方向涌去

## 六、历史与纪元

修仙世界的尺度以万年计。一段好的修真史让读者相信"这个世界在主角出生前已经运转了百万年"。

### 6.1 历史分层

```
太古/神话时代 —— 开天辟地、太古诸神、先天至宝诞生
  例：《完美世界》的尸骸仙帝时代（一切的源头）
  叙事定位：背景和传说，不宜过多干涉主线

上古时代 —— 修仙文明的黄金时期
  通常设定：功法完善、大能辈出、大乘遍地走
  然后发生"上古大劫"→ 灵气衰退/大能陨落/功法失传
  例：《凡人》中的上古魔界入侵、《遮天》的黑暗动乱
  叙事定位：当今世界的"废墟"和"遗迹"的来源

中古时代 —— 当代势力格局的雏形形成期
  各大宗门在此时期创立/分裂/合并
  叙事定位：势力恩怨和秘境归属的历史依据

近古时代 —— 影响活着的角色的历史事件
  上一代人物的恩怨（主角师父的仇人/已故天才的传承）
  叙事定位：推动当前剧情的直接历史动因

当代 —— 主角生活的时代
  正在发生的"历史"
```

### 6.2 大劫设计

"大劫"是仙侠世界中最核心的历史驱动力。每 N 万年一次的天地大劫（灵气潮汐/魔界入侵/天道重置），将旧的势力格局全部洗牌，新秩序在废墟上重建。

```
大劫类型：
  天地大劫 —— 灵气涨落、天道循环的必然（《牧神记》）
  外敌入侵 —— 魔界/异域/混沌生物的入侵（《完美世界》）
  至宝之争 —— 争夺某个能让道祖都动心的东西（《遮天》的成仙路）
  天人五衰 —— 纪元末的宇宙级灾难

大劫对世界观设计的意义：
  1. 解释"为什么上古辉煌不再"（灵气衰退/功法失传）
  2. 创造"遗迹→机缘"的合理性（每次大劫埋葬一批强者，留下大量遗产）
  3. 提供"大劫将至"的悬念（主角赶在下一次大劫前变强）
  4. 为主角的"逆天"提供理由（打破轮回/终结大劫/重塑天道）
```

## 七、飞升与上界体系

飞升是仙侠世界最独特的叙事装置——它是主角的"阶段性毕业典礼"，也是故事"刷新"的开关。

### 7.1 飞升机制设计

```
飞升的触发条件：
  修为达标 —— 达到人界修炼上限（化神后期/大乘），引动飞升天劫
  渡劫成功 —— 承受飞升天劫（通常比突破天劫更恐怖）
  接引 —— 部分作品中，上界势力可以主动"接引"下界天才
  跨界通道 —— 非飞升途径：传送阵/空间裂缝/偷渡
                《凡人》韩立就是通过空间节点偷渡到灵界的

飞升的去向：
  随机飞升 —— 渡劫后被天道随机"扔"到上界某处（《凡人》）
             → 最大不确定性，主角的"新手期"最有看头
  定向飞升 —— 飞升到指定势力/区域
             → 适合有上界传承/接引设定的作品
  飞升台 —— 飞升者统一到达的"新手村"
            → 各势力在此抢人/收保护费，价值观冲突的最佳舞台
```

### 7.2 上界的差异化设计

上界不应该只是"人界的放大版"。为上界赋予独特的生态：

```
人界 vs 灵界/上界的差异维度：
  灵气浓度 —— 上界灵气是人界的百倍，修炼速度倍增
  力量上限 —— 人界的元婴老祖到灵界只是"还行"
  种族构成 —— 人界以人族为主/灵界万族共存
  社会规则 —— 人界有宗门秩序/灵界可能更蛮荒（实力即规则）
  资源格局 —— 人界抢灵石/灵界抢法则碎片/仙界抢道果
  时间尺度 —— 上界修士的闭关动辄千年（人界修士一共才活千年）
  文化冲击 —— 飞升者在上界面临歧视/排挤/降维打击
```

### 7.3 经典作品中的飞升体系参考

| 作品 | 飞升/跨界设计 | 特色 |
|------|-------------|------|
| 《凡人修仙传》 | 人界→灵界（渡劫飞升/偷渡）→仙界 | 偷渡灵界的章节是全书的转折点——韩立失去一切靠山，从零开始 |
| 《遮天》 | 各星域由五色祭坛/星门连通 | 不是"飞升"而是"换个地图"，每个星域有独立文明 |
| 《仙逆》 | 洞府界→封界→仙罡大陆，每层都是牢笼 | 以"打破牢笼"为飞升隐喻，哲学意味浓厚 |
| 《莽荒纪》 | 三界→混沌世界，需要自己开天辟地 | 飞升不是"进新地图"而是"创造新世界" |
| 《完美世界》 | 八域→九天十地→异域→界海→上苍之上 | 层层嵌套的更大威胁，每一层都是"真相"的逼近 |

## 八、常见陷阱

### 8.1 地图太小/太大

**太小**：全书只有三个宗门两个城市，读到中期就觉得世界已经"逛完了"。
**太大**：动辄"三千大世界""亿万星域"，但读者一个都记不住。
**对策**：先聚焦 1-2 个区域深度刻画（让读者对"天南""乱星海"产生情感连接），再逐步展开。读者是通过主角的眼睛认识世界的——确保主角所处的每个地方都有"此时此刻值得关心"的冲突。

### 8.2 势力没有"人格"

**问题**：太虚门和万剑宗除了名字不同，行事逻辑完全一样——都是"一般意义上的正道宗门"。
**对策**：给每个重要势力一个"人格标签"。太虚门是"保守派中的保守派——任何新事物都要先封印再说"。万剑宗是"一群剑痴——修炼以外的事都不关心，但有人侮辱剑道就拼命"。一个标签让读者记住一个势力。

### 8.3 秘境等于副本

**问题**：秘境描写变成"清怪→开宝箱→拿装备"的机械流程，完全没有叙事的不可预测性。
**对策**：每次秘境探险给一个"不可预知"的变量——时空错乱（进去三天、出来三百年）、秘境的主人还活着（"闯入者，你的道…有意思"）、出现了比宝物更重要的信息（"世界的真相"）。

### 8.4 上界存在感太弱或太强

**问题 A**：全书从不提及上界，飞升时读者一脸懵。
**问题 B**：前三章就频繁出现仙帝/神尊的意志干涉下界，失去了"小世界"的接地感。
**对策**：上界的影子应该像背景噪音——散修提到"那些传说中的上界修士"，古书里记载的"飞升录"，偶尔出现的"从上界掉落下来的东西"。让读者隐约感知到"上面还有更大的世界"，但不具体介入当前的剧情。

## 九、输出规范

### 输出文件

世界观设定应分散为多个文件，而非全部堆在一个文档中：

```
worldview/power-system.md          # 修炼体系（来自修仙体系设计技能）
worldview/geography-overview.md    # 地理总览（大陆/海域/灵脉走向）
worldview/realm-structure.md       # 世界层次结构（下界/灵界/仙界关系）
worldview/sects-and-factions.md    # 宗门与势力格局
worldview/secret-realms.md         # 重要秘境与洞天
worldview/history.md               # 历史纪元与大事件
worldview/society-and-economy.md   # 社会结构与经济体系
worldview/ascension.md             # 飞升与上界机制
```

### 每份文档的 Frontmatter

```yaml
---
type: worldview
category: <geography|faction|society|history|rule>
name: <要素名称>
status: draft
importance: <1-10>
related:
  characters: []
  chapters: []
  world_elements: [<关联的其他世界观文档路径>]
---
```

### 重要提醒

- 每写完一份文档后调用 `sync_index` 同步索引
- `related.world_elements` 字段需要准确填写关联文档的路径——这是后续章节写作时 `chapter_context` 工具检索的基础
- 涉及势力/地理/秘境的文档，在正文中尽量给出"与其他设定的关联"——"此秘境位于万剑宗以北三千里，与玄冥冰原有空间裂缝相连"
