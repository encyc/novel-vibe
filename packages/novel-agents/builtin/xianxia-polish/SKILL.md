# 仙侠文笔润色

文笔润色不是"把文字变漂亮"——它是确保全书文字质量、设定一致性和爽点分布的最后一道关卡。好的润色让 300 万字的小说读起来像一口气写成的；差的润色让读者在境界名称写错的那一章直接弃书。本技能提供仙侠特有的润色框架——从文风选择到术语统一，从爽点审阅到力量体系自查。

## 设计原则

1. **一致性 > 华丽度。** 100 个漂亮的句子 + 1 处境界称呼错误 = 读者不再信任你。文笔润色的第一任务是确保"全书没有矛盾"，第二任务才是"让好的段落更好"。

2. **文风服务于内容。** 不需要让每一句都"仙气飘飘"。战斗场景需要短句和速度感，修炼场景需要宁静和沉浸感，日常场景需要烟火气和松弛感。好的文风是在不同场景间灵活切换，而非用一个调子写完全书。

3. **删比写更重要。** 一个"有点水但还行"的段落应该被删掉，而不是被改得更漂亮。在润色阶段，有勇气删掉多余的 10% 字数，比有文采写出新的 10% 更宝贵。

## 一、文风选择与统一

仙侠网文分化出两大文风流派。选择一种作为主基调，在恰当的时刻借用另一种的点缀。

### 1.1 古典仙侠风（半文半白）

以《凡人修仙传》《遮天》《剑来》为代表——文字雅致、句式工整、多用典故意象。

**特征**：
```
句式：四六句穿插，长短错落，读起来有韵律感
  "韩立盘膝端坐，双手掐诀，口中咒语声不绝于耳。
   片刻后，身前青光一闪，一柄尺许长金色小剑浮现而出。"
  —— 前两句四字节奏，后两句长短交替，读起来如行云

用词：多使用古语/术语替代日常词
  不说"他飞走了" → "化作一道惊虹，破空而去"
  不说"灵气很多" → "灵气之浓，几乎凝为实质"
  不说"他很强" → 展示（剑光/气势/威压的描写）

意象：化用道教/佛教/神话典故
  "三花聚顶，五气朝元"（道教修炼术语，形容境界极高）
  "一花一世界，一叶一菩提"（佛家典故，用作功法的意象）
  "大鹏一日同风起，扶摇直上九万里"（庄子典故，用作飞升/突破的意象）

叙事距离：偏"远距离"——叙述者更像一个"说书人"
  不对角色的每个心理活动都展开
  留白，让读者自己体会角色的情感
```

**古典风的使用场景**：
- 大境界突破的仪式感描写
- 天劫/战斗的宏大场面
- 高人的对话（化神/大乘修士说话应带"古意"）
- 功法/法宝的说明文字

**古典风的常见陷阱**：
- 半文半白变成"不文不白"——文言不够纯粹，白话不够自然
- 过度使用典故——读者看不懂，等于没写
- 华丽的废话——"剑气纵横三万里，一剑光寒十九洲"很帅，但如果这句话跟剧情无关，删掉

### 1.2 现代网文风

以《斗破苍穹》《完美世界》《一念永恒》为代表——口语化、节奏明快、直接有力。

**特征**：
```
句式：短句为主，节奏感强
  "萧炎抬起头。
   嘴角有一丝血迹。
   但他的眼睛在发光。"
  —— 极短句制造强烈的节奏感，适合战斗和情绪爆发

用词：直接、接地气、甚至可以使用轻微的网络用语
  不避讳口语化的表达——角色的对话就是"人说的话"
  "三十年河东，三十年河西，莫欺少年穷！"
  —— 这句《斗破》最出圈的台词，之所以能出圈，
     正是因为它是"人能喊出来的话"而非文绉绉的书面语

叙事距离：偏"近距离"——读者紧贴主角的视角
  主角的心理活动展开充分，读者能"听到"主角的心声
  情感直接外放——主角愤怒时读者一起愤怒

幽默感：不排斥喜剧化处理
  《一念永恒》白小纯被妖兽追时"边跑边哭边骂"——
  古典风不可能出现的写法，但在现代网文风中极受欢迎
```

**现代风的使用场景**：
- 战斗高潮的热血段落
- 日常/社交场景的对话
- 主角的心理活动
- 爽点的"释放瞬间"（打脸/逆袭的高潮）

**现代风的常见陷阱**：
- 过于啰嗦——主角的心理活动展开到"这个想法我已经知道了三遍了"
- 网络梗的时效性——现在好笑的梗两年后读者看不懂
- 缺乏仪式感——重要的突破/战斗写得像平常一样平平无奇

### 1.3 两种文风的混用策略

全书统一用一种文风是安全的，但在恰当的时刻切换文风可以制造惊喜：

```
混用法则：
  叙事段落：选择一个主基调（如古典风），全书保持一致
  对话段落：可以偏向现代风（修士也是人，说话不会都文绉绉）
  关键段落：根据内容选择——
    突破场景 → 古典风（仪式感）
    日常对话 → 现代风（自然感）
    终极决战 → 古典风 + 现代风的交替（宏大感 + 热血感）

切换时注意：场景转换时文风可以切换，但同一个场景内不要切换
（突破时突然蹦出一句"牛X"会直接让读者出戏）
```

## 二、术语标准化检查

这是润色阶段最容易做、也最能显著提升阅读体验的工作。

### 2.1 术语标准化清单

```
检查项：
□ 境界称呼全书一致
   "金丹期"还是"金丹期大圆满"？"化神"还是"化神期"？
   选一个，全书统一。
□ 人物称呼一致
   同一角色在不同章节中的称呼是否相同？
   "韩立"/"韩道友"/"韩前辈"——不同人叫法不同是正常的
   但同一人（如旁白叙述）不能时而"韩立"时而"韩道友"
□ 地名一致
   "天南"还是"天南大陆"？"乱星海"还是"乱星海域"？
□ 功法/法宝名称一致
   同一部功法的名称不能在不同章节变化
   "青元剑诀" ≠ "青元剑法" ≠ "青元诀"——必须是同一个
□ 货币/单位一致
   灵石的品级划分（下品/中品/上品/极品）
   距离单位（里/千里/万里）
   时间单位（瞬息/盏茶/一炷香/时辰/日/月/年/甲子）
```

### 2.2 术语词典维护

建议在项目中使用一份"术语词典"文档（可存放于 `worldview/glossary.md`），供所有 Agent 在写作时检索：

```yaml
---
type: worldview
category: rule
name: 术语词典
status: locked
importance: 10
---
```

词典中记录：每个境界的标准称呼、每个主要角色的标准称呼（含各种场合下的叫法）、每个重要地名/功法/法宝的唯一名称。

## 三、力量体系一致性审查

这是仙侠小说最致命的"一致性风险"。境界称呼统一只是表面——力量体系的内在逻辑是否一致才是根本。

### 3.1 战力一致性检查清单

```
检查项：
□ 同一境界的修士战力是否合理？
   如果前期金丹修士可以一拳轰碎一座小山，
   后期金丹修士被一座小山挡住了去路——
   读者会发现，并且会吐槽。
□ 越级挑战的规则是否前后一致？
   如果前期设定"一个大境界差 = 碾压"
   后期主角金丹反杀元婴 —— 需要解释清楚凭什么
□ 功法的强度前后一致？
   前期说"此功法大成后可移山填海"
   后期主角修炼到更高境界了，"移山填海"成了平A ——
   这倒不是bug（因为主角变强了），但功法本身的上限需要保持一致性
□ 法宝的品阶对应关系一致？
   灵器 vs 金丹、宝器 vs 元婴 —— 法宝应该"配得上"使用者境界
   金丹期使用仙器应该极为吃力（越级使用法宝需要代价）
□ 丹药的效力和稀缺性一致？
   前期"筑基丹万分珍贵，万人争一粒"
   后期主角随手掏出一瓶当糖豆吃 ——
   如果主角已经会自己炼了，这合理；如果只是因为"写忘了"，这是bug
□ 寿元与时间线的对应？
   化神修士寿元2000岁 —— 那1000岁的化神修士应该是"中年"
   不要让500岁的元婴修士说出"老夫活了大半辈子"——
   500岁对于元婴修士来说确实不算老^^
```

### 3.2 力量体系审查的"硬规则"

```
规则一：境界不可随意提升
  不能因为剧情需要就让主角"临时突破"——
  除非这个突破有充分的铺垫（前文已有"瓶颈松动"的暗示）

规则二：能力不可随意遗忘
  主角三卷前学会的某个秘术，到了第六卷从未再使用——
  要么给出"遗忘"的理由（秘术的威力跟不上境界了/使用代价太高）
  要么让读者看到主角还在使用（哪怕只是"低阶法术随手放出"）

规则三：资源不可随意通胀
  前期100灵石是大数目 → 后期10000灵石是小数目 —— 这是正常的（通货膨胀）
  但基数需要一致——不能让前期"耗尽家产买一粒筑基丹"的100灵石
  等于后期"随便花"的100灵石

规则四：环境不可随意变强
  前期"元婴老祖神龙见首不见尾" → 后期化神多如狗 ——
  这是经典问题。解决方案：世界分层 → 前期在人界、后期在灵界/上界
  同一世界的战力上限不能变。
```

## 四、爽点分布审阅

作为 Chief Editor，在润色阶段需要从"宏观节奏"角度审阅全书的爽点分布。

### 4.1 爽点分布图

以每 50 章为一个"审查单元"：

```
为每个单元标注：
  爽点密度：该单元中有多少个"爽"的时刻？
    □ 太密（每章一个爽点 → 读者麻木，爽点贬值）
    □ 太稀疏（连续 10 章没有爽点 → 读者流失）
    □ 理想：每 2-3 章一个小爽点，10-15 章一个中爽点
  爽点类型分布：是否过度依赖某一种爽点类型？
    □ 全是"主角突破" → 单调
    □ 全是"打脸" → 肤浅
    □ 理想：突破/打脸/获得/揭示/关系进展——交替出现
  压制-爆发周期：是否形成完整的"压制→爆发"循环？
    □ 只有压制没有爆发 → 读者压抑
    □ 只有爆发没有压制 → 爆发没感觉
  情绪曲线：该单元的总体情绪走向是否合理？
    □ 连续高潮不喘息 → 读者疲劳
    □ 连续日常不出事 → 读者无聊
```

### 4.2 节奏诊断与修复

```
常见节奏问题及修复：

问题：连续三章没有剧情推进
修复：合并这三章的精华为一章，删掉剩余部分

问题：同一类型的爽点重复三次
修复：保留最好的一次，另外两次换成不同类型的爽点

问题：大战之后没有喘息直接进入下一场大战
修复：在中间插入 1-2 章的过渡（战后恢复/盘点收获/日常社交）

问题：某个设定花了 3 章解释但可以 3 段说完
修复：大幅压缩说明性文字——"世界设定"是给 Agent 看的，
      读者只需要在剧情中逐步感知设定即可
```

## 五、常见写作陷阱

以下是在润色仙侠网文时最常遇到的写作陷阱，每一个都可能让读者弃书。

### 5.1 修炼体系崩坏

```
症状：前期辛苦建立的力量体系，在后期被作者自己破坏
  - 主角跨越 3 个大境界斩杀对手（"境界还有意义吗"）
  - 前期说"金丹多如狗，元婴遍地走"，但筑基丹还是那么难求
  - 功法的品阶系统在后期形同虚设

修复：
  - 重新定义越级战斗的铁律，全文统一遵守
  - 力量体系升级需要"换世界"（飞升/跨界），而非"在同一个世界里战力膨胀"
  - 如果确实出现了体系崩坏——在润色阶段做结构性修改：
    缩减过于离谱的越级跨度、为关键战斗添加合理性解释
```

### 5.2 角色工具化

```
症状：角色不再是"人"，而变成了为剧情服务的"工具"
  - 反派存在的唯一目的就是被主角打脸
  - 道侣存在的唯一目的就是被主角保护/为主角牺牲
  - 配角说过的话、做过的事，都是为了让主角的某个行为显得合理

修复：
  - 为每个重要角色增加至少一个"与主角无关"的细节
    （她有自己的修炼目标/他有一个不涉及主角的恐惧/他在主角不在场时做了某个决定）
  - 检查每个反派：他为什么要和主角作对？
    如果是被"更高层的反派"指派 → 太薄，加一层自己的动机
```

### 5.3 描写通胀

```
症状：为了制造"震撼感"，不断加码描写的力度，最终词穷
  前期：一拳轰碎巨石 → 中期：一拳轰碎小山 → 后期：一拳轰碎大陆
  到了后期已经没有更大的东西可以轰碎了

修复：
  - 力量的展示应该从"物理破坏"转向"法则层面的影响"
    化神之后——不是打得更大，而是打得"更精准""更不可防御""更优雅"
  - 用"对比"替代"绝对值"
    "这一剑没有惊天动地的声势——但围观的三位元婴老祖同时变了脸色。"
    比 "这一剑毁天灭地" 更有力量
```

### 5.4 情绪透支

```
症状：为了让每章都"燃"，不断让主角处于愤怒/激动/决绝的情绪中
  后果：主角的情绪波动失去了可信度——读者不再共情

修复：
  - 章节之间安排情绪的"冷却期"——主角也需要发呆/放空/什么都不想
  - 最简单的检测：如果主角连续 20 章没有笑过或没有平静过——出问题了
```

### 5.5 信息揭露节奏失控

```
症状 A（揭露太早）：第 3 章就把全书的终极秘密告诉了读者
  → 失去了 2997 章的悬念

症状 B（揭露太晚）：到了第 2000 章读者还不知道"这到底是怎么回事"
  → 读者在想知道之前已经不在乎了

修复：
  - 重要信息的揭露应该分层次——
    第 1 层（10 章内）：引发好奇的"异常"（"为什么天地灵气在变弱？"）
    第 2 层（100 章内）：部分真相（"有人在抽取天地灵气。"）
    第 3 层（500 章内）：更大的部分（"抽取灵气的，是上界的某个存在。"）
    第 4 层（终局）：全部真相（"这个存在就是你自己——未来的你。"）
```

## 六、去AI味：识别与修复AI写作痕迹

AI 生成的仙侠文本有一系列可识别的"口癖"。这些模式不是"写得不好"——单看每一处都可以说是合理的修辞选择——但当它们在文本中以远超人类作者的密度出现时，读者会产生一种难以言说的"感觉不对"。本节的每一个模式都来自大量 AI 文本与人类作者文本的对比研究（参考 Wikipedia "Signs of AI writing" 体系及 humanizer 实践），适配为中文仙侠网文的检测规则。

核心原则：去 AI 味不是"把好句子改差"——是在保留文风主干的前提下，清除那些让读者潜意识觉得"这不是人写的"的痕迹。

### 6.1 句尾挂缀："彰显/展现/体现/诠释"家族

**AI模式**：AI 喜欢在描写之后挂一个"彰显了……""展现了……""体现了……""诠释了……"作为"分析性收尾"。人类作者写打斗，打完就是打完——读者自己会体会"这一剑有多强"。

```
AI味重：
  "这一剑斩落，天地色变，日月无光，彰显了他作为剑修的恐怖实力，
   也体现了青元剑诀第六层的惊天威能。"

人类味：
  "这一剑斩落。血洒长空。对面元婴老祖的护体灵光像纸一样裂开。"
```

**检测规则**：扫描每一处"彰显了/展现了/体现了/诠释了/折射出/反映出/印证了"。保留概率不超过 5%——即 20 个中有 19 个应该被改写或删除。改写方法：删掉分析句，让前文的描写自己说话；或者换成具体的、不可替代的信息。

### 6.2 形容词堆砌与"超级词汇"

**AI模式**：AI 写仙侠时对"宏大词汇"有近乎成瘾的依赖——震撼人心的、无与伦比的、惊天动地的、浩瀚无垠的、璀璨夺目的、深不可测的。每个词单独看都成立，但一段里出现三个以上，读者就开始闻到"AI 味"。

```
AI高频形容词（排名分先后）：
  惊天动地 / 无与伦比 / 深不可测 / 浩瀚无垠 / 璀璨夺目
  恐怖如斯 / 势不可挡 / 毁天灭地 / 震撼人心 / 不可思议
  前所未有 / 令人窒息的 / 霸道无匹 / 凌厉至极

AI高频程度副词：
  无比 / 极其 / 惊人地 / 不可思议地 / 难以想象地 / 前所未有地
```

**检测规则**：每 1000 字中，上述"超级词汇"的出现次数不应超过 2 次。超过则逐一检查：这个词能不能换成更具体的描写？"深不可测的眼神"→ 删掉"深不可测的"，用角色的具体行为或对话来传达这个意思。

**核心洞察**：恐怖的不是词本身——是"密度"。人类作者也会用"惊天动地"，但一章用一两次。AI 一章能用十几次。

### 6.3 "不仅……而且……"与排比依赖

**AI模式**：AI 对"不仅……而且……"句式和三连排比（"剑气纵横、杀意凛然、势不可挡"）有结构性偏好。这是训练数据中"优秀作文"模板的残留。

```
AI味重：
  "这次突破不仅让他踏入了金丹期，而且为他打开了元婴之路。
   这不仅是一次境界的提升，更是一次生命的蜕变。"

人类味：
  "他睁开了眼。金丹在丹田中缓缓旋转，像一颗新生的太阳。
   从这一天起，他有五百年好活。"
```

**检测规则**：
- "不仅……而且/更/还……"：每 5000 字不应超过 1 次
- 连续三个及以上四字短语并置（"剑气纵横、杀意凛然、势不可挡"）：每 3000 字 1 次为合理上限
- "规则三"检测：如果一段话可以写成"A、B、C"三连而不损失信息——这就是三连。改成"或删或留一二"。

### 6.4 破折号密度

**AI模式**：AI 生成的文本中，破折号（——）的出现频率远超人类作者。人类作者偶尔用破折号做插入补充；AI 在几乎每一段里都至少用一个。

```
AI味重：
  "韩立御剑而起——七十二柄青竹蜂云剑在身后展开——剑光化作一道惊虹——
   目标直指——元婴老祖的咽喉。"

人类味：
  "韩立御剑而起。七十二柄青竹蜂云剑在身后如羽翼般展开。
   剑光直指元婴老祖的咽喉。"
```

**检测规则**：每 500 字中破折号不超过 1 对。超标则逐一替换：改为句号（拆成两句）、改为逗号（轻松插入）、改为冒号（引入解释）、或调整语序使插入变成正文的一部分。

### 6.5 "可谓是/堪称/无疑/显然"——伪强调

**AI模式**：AI 喜欢在陈述句前面或后面加上"强调标记"——可谓是、堪称、毫无疑问、显然、毋庸讳言。这些词的功能是告诉读者"这很重要"——但好的写作让读者自己觉得"这很重要"。

```
AI味重：
  "韩立此举，毫无疑问地改变了天南修仙界的格局。
   这堪称千年未有之大变局。可谓是前无古人后无来者。"

人类味：
  "韩立杀了那个元婴修士。三天之内，整个天南的灵脉分配方案重新洗牌。
   这是天南千年以来第一次有散修斩杀宗门元婴。"
```

**检测规则**：全文中"可谓是/堪称/毫无疑问/显然/毋庸讳言/不言而喻"的总出现次数，不应超过章节数×0.5（即每两章最多 1 次）。

### 6.6 句首套子："在……之中/之下/的同时"

**AI模式**：AI 写仙侠时频繁以"在……中/下/的同时"作为句子开头——"在灵气的滋养下""在天地法则的笼罩之中""在众人震惊的目光中"。这种句式本身没有错，但当它成为句首的默认选择时，所有句子开始长得像。

```
AI味重：
  "在灵气的疯狂涌入下，韩立的经脉迅速扩张。
   在剧痛之中，他咬紧牙关。
   在金丹即将碎裂的瞬间，一股暖流从丹田深处涌出。"

人类味：
  "灵气疯狂涌入，韩立的经脉被撑得吱吱作响。
   剧痛。但他咬紧牙关。
   金丹即将碎裂——丹田深处突然涌出一股暖流。"
```

**检测规则**：每 500 字中"在……中/下"句首不超过 1 次。超标时：删掉"在……中"直接写动作；或把"在……的同时"改成"一边……一边……"或直接断成两句。

### 6.7 "让我们/我们来看/回过头来看"——导览式叙事

**AI模式**：AI 经常在文本中扮演"导游"角色——"让我们来看看这一战的结果""回过头来看，这个选择改变了……"。人类作者不干这事——他们直接写结果。这是 AI 从"教程/博客"训练数据中继承的口癖。

```
AI味重：
  "让我们来看看这一战的结果。回过头来看，韩立的每一次选择
   都在指引他走向那条唯一的道路。"

人类味：
  "这一战，韩立杀了三个魔修，损失了十二柄飞剑。
   他坐在尸堆旁算了一笔账——不值。但至少他还活着。"
```

**检测规则**："让我们/我们来看/回过头来看/值得一提的是/需要指出的是/值得关注的是"——全文出现次数应为零。这些都是"元写作"（关于写作的写作），在小说中没有存在的理由。

### 6.8 结尾"正能量收束"

**AI模式**：章节/段落的结尾，AI 倾向于用一个"向上"的句子收尾——"他的未来充满了无限可能""新的征程就此展开""属于他的时代，才刚刚开始"。这是 ChatGPT 的"安全对齐"在文本层面的投影——AI 被训练成给出积极、安全、令人满意的收尾。

```
AI味重：
  "韩立望着远方。属于他的传奇，才刚刚开始。
   前路漫漫，但未来可期。新的时代，已经拉开帷幕。"

人类味：
  "韩立望着远方。来杀他的人应该已经在路上了。
   他得在日落之前布好第三层禁制。"
```

**检测规则**：每章的结尾如果可以被替换为"明天会更好"而不丢失任何具体信息——这个结尾就是"正能量收束"。删掉，换成具体的、有信息量的、甚至不一定是正面的内容。人类作者的章节结尾更偏爱"钩子"（悬念/紧张/未解之谜）而非"总结"。

### 6.9 "真正的……是……"——伪深度句式

**AI模式**：AI 酷爱"真正的 X，不是 Y，而是 Z"这个句式——"真正的强者，不是没有恐惧，而是直面恐惧""真正的力量，不是毁灭，而是守护"。这个句式表面上有思辨深度，实际上 99% 的情况下是在重复一句陈词滥调。

```
AI味重：
  "真正的强者，不是拥有最强大的功法，而是在最黑暗的时刻
   仍然选择前行的人。"

人类味：
  "韩立不觉得自己是强者。他只是觉得——死在这里太亏了。"
```

**检测规则**："真正的……不是……而是……"在全文中的出现次数应为零。如果确实有一个深刻的洞见需要用对比来表达——用具体的角色行为或对话来展示，而非用这个句式直接宣告。

### 6.10 短句轰炸制造假紧张

**AI模式**：AI 在想要制造"紧张感"时，会连续输出 5 句以上不足 10 字的极短句。人类作者的短句使用是克制的、有选择性的——"剑光一闪。"很有效。但连续 8 句短句叠在一起——"剑光亮起。天地变色。风云倒卷。日月无光。一片死寂。没有人说话。没有人动。"——这是 AI 在"表演紧张"。

```
AI味重（连续短句轰炸）：
  "剑光亮起。天地变色。风云倒卷。日月无光。一片死寂。
   没有人说话。没有人动。所有人都看着那一剑。"

人类味：
  "剑光亮起。围观的三位元婴老祖同时后退了一步——
   不是因为害怕，是因为他们认出了这个剑招。"
```

**检测规则**：如果连续出现 4 句以上不足 10 字的极短句——至少改掉其中 2 句，扩展为有具体信息的长句，或合并为一个复合句。

### 6.11 同义词轮换过度

**AI模式**：AI 有明显的"避复"倾向——同一个角色在同一段里被换成三种不同的称呼。这是模型训练中"惩罚重复"机制的副作用。人类作者不介意在同一段里反复叫一个人的名字。

```
AI味重：
  "韩立收起飞剑。这位黄枫谷弟子环顾四周。青年发现敌人的踪迹。
   这位散修出身的小子做好了战斗准备。"

人类味：
  "韩立收起飞剑，环顾四周——发现了敌人的踪迹。他不动声色地
   捏了一个剑诀。"
```

**检测规则**：同一段内，同一角色不要用超过两种不同的称呼方式（名字 + "他/她"）。如果一段里出现了"韩立/这位青年/散修/黄枫谷弟子"四种叫法——选一种（通常是"韩立"或"他"），其余替换。

### 6.12 对话中的"客服语调"

**AI模式**：AI 写的角色对话往往过于礼貌、过于完整、过于"建设性"。真实的人说话是破碎的、跳跃的、带情绪的、有时前言不搭后语的。AI 写修士对话像公司开会——"我理解你的担忧，我认为我们可以通过合作来解决这个问题"。

```
AI味重：
  "韩道友，我理解你此刻的疑虑。但我认为，在面对魔道威胁这件事上，
   我们两派应当搁置过往的成见，携手合作。这对双方都有好处。"

人类味：
  "姓韩的，你看不惯我，我也看不惯你。但魔道那帮人明天就到。
   咱俩的事——打完他们再算。"
```

**检测规则**：朗读每一段对话。如果听起来像"两个 HR 在调解办公室纠纷"——重写。好的仙侠对话应该：有情绪（愤怒/讽刺/不耐烦/冷笑）、有信息不对称（说一半藏一半）、有潜台词（表面说A其实在说B）。

### 6.13 去AI味工作流

逐章审查时，按以下顺序执行：

```
第一步：扫描破折号密度（最快、最明显的信号）
  → 500字/对，超标则全部替换

第二步：扫描超级词汇和形容词堆砌
  → 对照 6.2 的词汇清单，逐词判断保留/删除/改具体

第三步：扫描句首套子和句尾挂缀
  → "在……中/下"句首 + "彰显了/展现了"句尾 → 改写

第四步：扫描句式模板
  → "不仅……而且……"、"真正的……是……"、"让我们……" → 删除或改写

第五步：对话朗读检查
  → 每段对话读出来，判断是否"客服腔"

第六步：结尾检查
  → 每章结尾是否"正能量收束" → 删总结、加钩子
```

## 七、润色工作流

### 7.1 Chief Editor 的全局审阅流程

```
第一步：术语一致性扫描
  逐个检查：境界称呼、人物名字、地名、功法名称、法宝名称、货币单位

第二步：力量体系一致性审查
  对照 worldview/power-system.md ，检查所有章节中的战力描写

第三步：爽点分布审阅
  画出每 50 章的爽点分布图，识别节奏问题

第四步：陷阱检测
  逐项检查第五节中的五种常见陷阱

第五步：出具审阅报告
  将发现的问题按严重程度排序：
    致命（必须修复）：战力体系矛盾、核心设定冲突
    重要（强烈建议修复）：节奏问题、角色工具化
    建议（可选修复）：措辞优化、多余的形容词
```

### 7.2 Writer 的段落级润色流程

```
第一步：读一遍，标注所有"读起来不顺"的段落

第二步：针对问题段落——
  □ 句子太长？拆短（超过 50 字的句子在网文中需要特别的理由）
  □ 形容词堆砌？去重（"恐怖的、可怕的、凌厉的、无与伦比的"——保留一个）
  □ 信息重复？删除（前一段已经说过的事，不要再解释一遍）
  □ 过于抽象的描写？具象化（"他的气势很强大"→ 展示强大）

第三步：检查战斗/修炼段落的感官维度
  □ 至少覆盖视觉 + 一个其他感官（听觉/触觉/灵觉）

第四步：检查对话
  □ 每个角色说的话是否符合其性格？
  □ 对话是否可以更"有潜台词"？（表面说A其实在说B）
```

润色阶段的输出包括：

```
审阅报告（Chief Editor 输出）：

```
